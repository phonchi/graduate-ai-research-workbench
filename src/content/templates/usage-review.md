## 何時使用與怎麼填

挑一個剛完成的專案，或幾次同類任務，把對話與工作紀錄提供給 AI。先限定範圍，才能知道它的建議依據哪些經驗。若還沒有提供紀錄，請先補上，不能只貼示例就期待它知道你的使用歷史。

有 `/insights` 等功能的工具可先產生內建報告，再以這份模板追問具體改進。沒有用量資料也能回顧交辦習慣；成本表是選填，不妨先找出一次可以避免的重做。

比較成本時，總 token 要包含可取得的模型呼叫與分身用量，並註明缺少的部分；等待、檢查與重做則計入完成時間。觀察到可重複的好做法後，再寫入[工作守則](../workspace-rules/)。更完整的計費說明見 [Claude Code 成本管理文件](https://code.claude.com/docs/en/costs)。
