## 何時使用與怎麼填

Git 的提交（commit）會記錄一組檔案變更，讓你之後能比較或回到先前版本。先確認哪些檔案屬於這次成果，再建立本機存檔；提交完成後記下實際編號。

推送（push）是把提交送到遠端儲存庫。遠端可用來共同編輯，也可能是私人儲存庫；網站發布還需要部署流程。請按這次的目的選用後半段，筆記存檔做到本機提交就可以結束。

發布網站時，要從實際網址再看一次頁面。敏感原始資料則另用適當的儲存與備份方式。操作入門見[Git 與 GitHub](../../tools/git-github/)。
