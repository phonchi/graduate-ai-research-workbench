## 用法

完成一個可清楚命名的階段就建立存檔點；推送前檢視差異，部署後從正式網址再驗一次。可請 Agent 協助執行，但是否公開仍由你決定。

## 完成後你會得到什麼

一個可追溯、可協作、可回到上一版的研究或網站版本，以及公開版本確實可用的檢查紀錄。

## 不適用情境

Git 不是備份敏感資料的地方，也不會自動檢查研究正確性；密鑰、個資、受限制資料與大型原始資料應使用合適的安全儲存方案。
